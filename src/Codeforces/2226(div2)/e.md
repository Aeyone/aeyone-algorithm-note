## 题意简述

给定前缀数组 $c$，每个元素 $c_i$ 可以选择一个 $b_i \ge 1$，然后变成 $c_i \bmod b_i$。

要求每个前缀能得到的最大 mex。

<a id="core"></a>
## 核心转化

一个数 $x$ 能变成哪些值？

- 可以不变成 $x$：选 $b > x$。
- 若要变成 $y < x$，需要存在 $b > y$ 且 $x \bmod b = y$。
- 只要 $x > 2y$，选 $b = x-y$ 就能做到。

所以：

$$
x \to y \Longleftrightarrow y=x \text{ 或 } x>2y
$$

也就是：

$$
x \text{ 可变成 } \{0,1,\ldots,\lfloor (x-1)/2 \rfloor\} \text{ 或 } x
$$

于是问题变成匹配：

要让 mex 至少为 $K$，就要用不同元素覆盖目标值 $0,1,\ldots,K-1$。

<a id="check"></a>
## 判定一个 mex

固定 $K$。

如果某个目标值 $x < K$ 在数组中出现过，那么可以钦定一个值为 $x$ 的元素直接覆盖目标 $x$。

注意：每个目标值 $x$ 最多只需要一个原值 $x$ 来固定覆盖。多出来的值为 $x$ 的元素不能继续固定覆盖 $x$，只能作为普通可变元素，能力退回到 $[0,\lfloor (x-1)/2 \rfloor]$。

这是不亏的：如果原来用大数覆盖 $x$，而值为 $x$ 的元素去覆盖更小值，那么交换后仍然合法。

剩下的元素都只剩一种能力：

$$
\text{可以覆盖任意 } y \le \lfloor (x-1)/2 \rfloor
$$

这就是经典的“单位任务 + deadline”判定。

从大到小扫目标值：

```text
pool = 0

for y = K-1 ... 0:
    pool += deadline 为 y 的可变元素数量
    pool += 是否存在一个被钦定为 y 的固定元素
    pool -= 1
    如果 pool < 0，则 mex K 不可行
```

这里 `pool` 表示当前能拿来填目标 `y` 以及更低目标的元素余量。

例如有两个原值 `3` 和一个原值 `4`，并且当前 `K=5`。其中只能固定一个 `3` 覆盖目标 `3`，只能固定一个 `4` 覆盖目标 `4`。多出来的那个 `3` 作为可变元素时，deadline 是 `1`，不能覆盖目标 `2`。

<a id="why-segtree"></a>
## 为什么要线段树

如果每次判断一个 mex `K` 都重新从 `K-1` 扫到 `0`，单次就是 `O(K)`，前缀全部做会超时。

把上面的扫描写成数组：

```text
delta[y] =
    deadline 正好为 y 的可变元素数量
  + 是否存在一个固定覆盖 y 的元素
  - 目标 y 是否需要覆盖
```

判断 mex `K` 可行，就是从右往左扫 `delta` 时，累计和始终不能小于 `0`：

```text
sum = 0

for y = K-1 ... 0:
    sum += delta[y]
    if sum < 0:
        不可行
```

所以线段树维护的不是答案本身，而是这个“从右往左扫时的最小累计和”。

线段树每个节点维护：

- `sum`：区间总和；
- `mn`：从右往左扫这个区间时，累计和的最小值。

合并两个儿子时，设当前区间是 `[l,r]`，左儿子是 `L`，右儿子是 `R`。因为扫描顺序是从右到左，所以先经过 `R`，再经过 `L`：

```text
sum = L.sum + R.sum
mn = min(R.mn, R.sum + L.mn)
```

于是判断当前 mex 是否可行，只需要看根节点：

```text
root.mn >= 0
```

检查是 `O(1)`，只有更新 `delta[y]` 时才需要线段树单点更新，复杂度 `O(log V)`。

<a id="dynamic"></a>
## 前缀动态维护

答案随前缀单调不降。

维护当前答案 `K`，表示当前已经能覆盖目标 `0..K-1`。每加入一个数后，不断尝试让目标 `K` 也被覆盖；成功就 `K++`。

虽然某个前缀答案可能一次跳很多，但整个测试中 `K` 最多只会增加 `n` 次。

每个元素任何时刻只有一种身份：

- 可变元素：贡献到 `deadline(x)=\lfloor (x-1)/2 \rfloor`；
- 固定元素：当目标 `x` 已经需要覆盖时，贡献到 `x`。

加入新数 `x` 时：

```text
如果 x < K 且还没有固定过原值 x：
    固定它，delta[x] += 1
否则：
    先当可变元素，delta[deadline(x)] += 1
```

注意 `x >= K` 时，目标 `x` 还不需要覆盖，所以不能提前固定，只能先放进可变池。

当 `K` 增加到需要覆盖目标 `K` 时，如果已经存在一个还没固定过的原值 `K`，就把它从可变池转成固定元素：

```text
delta[deadline(K)] -= 1
delta[K] += 1
```

例如当前 `K=3`，加入 `x=6`：

```text
目标 6 现在还不需要覆盖
所以 6 先作为可变元素：
delta[2] += 1
```

以后如果 `K` 增加到 `6`，准备覆盖目标 `6`：

```text
把这个 6 从可变池转成固定元素：
delta[2] -= 1
delta[6] += 1
```

这样同一个元素不会被同时算作固定元素和可变元素。

<a id="complexity"></a>
## 复杂度

每个元素加入一次，答案总共增加至多 $n$ 次。

每次只做常数次线段树单点更新，所以复杂度：

$$
O(n \log V)
$$

其中 $V$ 是值域规模，本题总值域可控。
