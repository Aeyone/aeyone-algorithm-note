## 题意

给定一个字符串 `s`，要把它切成若干个非空连续段。一个切法的“副歌部分”是所有段中字典序最大的那一段。

要求在所有切法中，让这个“最大段”尽量小，并输出这个最小可能的最大段。

<a id="tle"></a>
## TLE 原因

原代码从单字符开始分段，然后反复扫描相邻段：

- 如果左段小于右段，就把它们合并。
- 每次比较用哈希加二分求 LCP。
- 外层会反复扫描，直到没有段能合并。

这个过程最坏情况下会进行很多轮，每轮又要比较大量相邻段，所以会退化到接近平方级，再乘上哈希二分的常数，`1s` 很容易 TLE。

<a id="core"></a>
## 核心结论

这个问题等价于求字符串的 Lyndon 分解中的第一段。

Duval 算法会把字符串分成若干 Lyndon 串：

$$
s=w_1w_2\cdots w_k
$$

并且满足：

$$
w_1 \ge w_2 \ge \cdots \ge w_k
$$

所以直接按照这个切法，最大段就是 `w1`，答案至多是 `w1`。

另一方面，`w1` 是一个 Lyndon 串。如果强行把 `w1` 拆开，拆出来的某一段一定会让当前切法的最大段不小于 `w1`。因此答案不可能小于 `w1`。

所以答案就是第一段 Lyndon 因子。

<a id="duval"></a>
## Duval 求第一段

只需要跑 Duval 的第一轮：

```cpp
int i = 0, j = 1, k = 0;
while (j < n && s[k] <= s[j]) {
    if (s[k] < s[j]) {
        k = i;
    } else {
        k ++;
    }
    j ++;
}

cout << s.substr(0, j - k) << '\n';
```

其中 `j - k` 就是第一段 Lyndon 因子的长度。

<a id="complexity"></a>
## 复杂度

每个字符在 Duval 中只会被常数次访问，单组时间复杂度 $O(|s|)$，总复杂度 $O(\sum |s|)$，空间复杂度 $O(1)$。
