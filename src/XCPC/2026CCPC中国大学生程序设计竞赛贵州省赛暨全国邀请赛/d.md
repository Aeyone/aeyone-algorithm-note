<a id="statement"></a>
## 题意

给定数组 `a` 和阈值 `k`。一个区间 `[L,R]` 被称为积极互动小组，当且仅当它内部存在一个子区间，子区间和至少为 `k`。每次询问给出 `x`，问长度不超过 `x` 的积极互动小组数量。

<a id="approach"></a>
## 你的做法

先做前缀和。对每个子区间起点 `i`，二分最小的右端点 `res[i]`，使得存在某个 `j` 满足 `i <= j <= res[i]` 且：

$$
sum(i,j) \ge k
$$

代码里用 ST 表维护前缀和最大值，所以可以判断：

$$
\max prefix(i..mid) \ge k + prefix(i-1)
$$

这一步能处理负数，因为虽然数组不是单调的，但区间前缀最大值随着 `mid` 右移一定不会变小，所以可以二分。

<a id="suffix-min"></a>
## 为什么要后缀最小

上一步的 `res[i]` 表示“必须从 `i` 开始”的合法子段最早结束位置。

但一个大区间 `[L,R]` 只要求内部存在合法子段，子段起点可以是任意 `i >= L`。

所以固定左端点 `L` 时，最早能让 `[L,R]` 合法的右端点应该是：

$$
\min_{i \ge L} res[i]
$$

这就是代码里从右往左做：

```cpp
for (int i = n - 1; i >= 0; i --) {
    res[i] = min(res[i], res[i + 1]);
}
```

<a id="answer"></a>
## 如何回答询问

固定左端点 `i`，设最早合法右端点是 `res[i]`。

那么所有合法大区间是：

```text
[i, res[i]], [i, res[i]+1], ..., [i, n-1]
```

它们的长度范围是：

$$
res[i]-i+1 \le len \le n-i
$$

对于每个 `i`，它对答案函数的贡献是一个从某个长度开始每次加 `1` 的斜坡，所以用两次前缀和差分维护：

```cpp
int len = res[i] - i + 1;
ans[len] ++;
ans[n - i + 1] --;
```

做两次前缀和后，`ans[x]` 就是长度不超过 `x` 的积极互动小组数量。

<a id="pitfalls"></a>
## 易错点

`k == 0` 必须特判。题面允许空区间，空区间和为 `0`，所以此时所有区间都合法。

询问 `x` 的答案直接是长度不超过 `x` 的所有区间数：

$$
\frac{x(2n-x+1)}{2}
$$

差分数组需要能写到 `n+1` 这个哨兵位置，因此 `ans` 至少开到 `n+2` 个元素。

<a id="complexity"></a>
## 复杂度

ST 表预处理 $O(n \log n)$，每个起点二分 $O(\log n)$，总时间复杂度 $O(n \log n + Q)$，空间复杂度 $O(n \log n)$。
