## 题意

有 $n$ 枚硬币，第 $i$ 枚硬币正面向上的概率为 $p_i$。求正面数量严格大于反面数量的概率。

<a id="state"></a>
## 状态定义

`dp[j]` 表示当前已经处理过的硬币中，恰好有 `j` 枚正面向上的概率。

初始：

$$
dp[0]=1
$$

<a id="transition"></a>
## 转移

处理一枚正面概率为 `p` 的硬币：

```cpp
dp[j] = dp[j - 1] * p + dp[j] * (1 - p);
```

含义：

- 从 `j - 1` 个正面转移来：当前硬币是正面。
- 从 `j` 个正面转移来：当前硬币是反面。

因为是一维滚动数组，`j` 必须从大到小枚举，避免覆盖还没用过的旧状态。

<a id="bug"></a>
## 注意点

题目要求正面数量严格大于反面数量，也就是正面数量必须满足：

$$
j > n-j
$$

所以：

$$
j > n/2
$$

答案应该从 `n / 2 + 1` 开始累加。

如果题目保证 `n` 一定是奇数，那么原代码写的：

```cpp
for (int i = (n + 1) / 2; i <= n; i ++)
```

和 `n / 2 + 1` 是一样的，不会错。

只有当 `n` 可能为偶数时，`(n + 1) / 2` 才会把平局情况也算进去。例如 `n = 2` 时，它会从 `1` 开始累加，但正确应该只统计 `2` 个正面。

<a id="complexity"></a>
## 复杂度

时间复杂度 $O(n^2)$，空间复杂度 $O(n)$。
