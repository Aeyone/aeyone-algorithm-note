<a id="statement"></a>
## 题意

一开始有 `k` 只特殊生物，每只生物只能活 `1` 天。死亡时，它会以概率 `p[i]` 产生 `i` 只新生物，其中 `0 <= i < n`。

求 `m` 天内所有生物都死亡的概率。

<a id="state"></a>
## 状态定义

先只考虑从 `1` 只生物开始。

设 `f[t]` 表示从 `1` 只生物开始，`t` 天内整棵后代全部死亡的概率。

初始：

$$
f[0]=0
$$

因为第 `0` 天刚开始时，这只生物还活着，不可能已经全部死亡。

<a id="transition"></a>
## 转移

第 `1` 天，这只生物死亡并产生 `i` 只后代，概率是 `p[i]`。

如果要在 `t` 天内全部死亡，那么这 `i` 只后代都必须在剩下的 `t-1` 天内死亡。

每只后代独立，所以概率是：

$$
f[t-1]^i
$$

因此：

$$
f[t]=\sum_{i=0}^{n-1}p[i]\cdot f[t-1]^i
$$

代码里只需要保存上一天的值：

```cpp
double cur = 0;
for (int day = 1; day <= m; day ++) {
    double nxt = 0;
    double pw = 1;
    for (int i = 0; i < n; i ++) {
        nxt += p[i] * pw;
        pw *= cur;
    }
    cur = nxt;
}
```

<a id="k"></a>
## 初始有 k 只

一开始有 `k` 只生物，它们的繁衍过程互相独立。

如果从 `1` 只开始，`m` 天内灭绝的概率是 `f[m]`，那么从 `k` 只开始，全部灭绝的概率是：

$$
f[m]^k
$$

<a id="pitfalls"></a>
## 易错点

题面说产生数量范围是 `[0,n-1]`，所以应该读入 `n` 个概率 `p[0]..p[n-1]`。样例里 `n=3` 时也给了 `3` 个概率。

概率必须用 `double` 读入，不能用 `int`。

样例第四组的真实值是 `0.31640625`，输出到 `7` 位小数时正好卡在进位边界。为了避免浮点显示误差，可以输出时加一个很小的 `eps`。

<a id="complexity"></a>
## 复杂度

每组询问枚举 `m` 天，每天枚举 `n` 种繁衍数量。时间复杂度 $O(nm)$，空间复杂度 $O(1)$。
