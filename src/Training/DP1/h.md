<a id="problem"></a>
## 题意

给定 `n` 个正整数，问有多少种非空选取方案，使得选出的数平均数为 `x`。

结果对 `1000000007` 取模。

<a id="core"></a>
## 核心转化

设选出的集合是 `S`。

平均数为 `x` 等价于：

$$
\frac{\sum_{i \in S} a_i}{|S|}=x
$$

也就是：

$$
\sum_{i \in S} (a_i-x)=0
$$

所以把每个数变成：

$$
b_i=a_i-x
$$

问题就变成：有多少个非空子集，使得选出的 `b_i` 之和为 `0`。

<a id="dp"></a>
## DP 设计

因为 `1 <= a_i,x <= 100`，所以：

$$
-99 \le b_i \le 99
$$

且 `n <= 200`，总和范围约为 `[-20000,20000]`。

用偏移量处理负数下标：

```cpp
offset = 20000
dp[s + offset] = 当前选出若干数，偏移和为 s 的方案数
```

初始：

```cpp
dp[offset] = 1
```

表示空集。

每读入一个数 `a`，令 `v = a - x`，做 01 背包：

```cpp
ndp = dp

for s:
    ndp[s + v] += dp[s]
```

最后：

```cpp
ans = dp[offset] - 1
```

减掉空集。

<a id="complexity"></a>
## 复杂度

总和范围约 `40001`，所以：

```cpp
时间复杂度：O(n * 40000)
空间复杂度：O(40000)
```

可以通过本题数据范围。
