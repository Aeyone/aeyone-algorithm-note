## 题意

在一个圆环数组上，选两段连续、不重叠、非空的区间，使两段区间和最大。

<a id="core"></a>
## 关键转化

把每个位置看成“选”或“不选”。

两段圆弧等价于：圆环上被选中的位置形成不超过 `2` 个连续块，并且至少选中 `2` 个位置。

注意：如果被选中的是一个连续块，只要长度至少为 `2`，也可以从中间拆成两段相邻的不重叠区间。

所以问题变成：

```text
在圆环上选若干位置
要求选中的位置形成不超过 2 个连续块
且选中数量至少为 2
最大化选中位置之和
```

<a id="dp"></a>
## DP 状态

枚举第一个位置是否被选：`first = 0/1`。

然后线性扫描 `1..n`，维护：

```cpp
dp[last][runs][cnt]
```

含义：

- `last`：上一个位置是否被选；
- `runs`：当前线性序列中已经形成了几个选中块，最多记到 `3`；
- `cnt`：选中数量，最多记到 `2`；
- 值：当前最大选中和。

转移时当前位 `take = 0/1`：

```cpp
newRuns = runs + (take == 1 && last == 0)
newCnt = min(2, cnt + take)
```

如果 `take = 1`，就加上当前 `a[i]`。

为什么 `runs` 要记到 `3`？

因为我们是从位置 `1` 把圆环切开。若 `first = 1` 且最后一个位置也被选，那么线性上的第一个选中块和最后一个选中块在圆环上会合并。

例如圆环上是 `2` 个块，切开后可能变成线性上的 `3` 个块：

```text
111 000 11 000 111
```

最后判断时：

```cpp
circleRuns = runs

if (first == 1 && last == 1) {
    if (runs == 1) circleRuns = 1;
    else circleRuns = runs - 1;
}
```

只要满足：

```cpp
cnt == 2 && circleRuns <= 2
```

就可以更新答案。

<a id="bug"></a>
## 当前代码的问题

当前 [r.cpp](./r.cpp) 用的是 doubled array 加 `set` 找区间。

核心问题是：它没有严格保证两段区间映射回原圆环后不重叠。

反例：

```text
2
-3 -2
```

正确答案只能是：

```text
-5
```

因为必须选两个非空不重叠区间，只能分别选 `-3` 和 `-2`。

但当前代码会输出 `-4`，相当于重复利用了值为 `-2` 的位置。

<a id="complexity"></a>
## 复杂度

状态数量是常数级：

```text
first: 2
last: 2
runs: 0..3
cnt: 0..2
```

所以总复杂度：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```
